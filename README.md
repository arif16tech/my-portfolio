# Arif — Portfolio

A modern, cinematic developer portfolio featuring interactive video scrubbing, smooth scrolling, and dynamic project showcases.

## Tech Stack

- **Framework**: React 18 & Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Animation**: GSAP & ScrollTrigger
- **Scroll**: Lenis Smooth Scroll
- **Icons**: React Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Configuration

- `src/data.js` — Update your bio, tech stack, projects, and contact info.
- `src/components/` — Modular page sections (`Hero`, `Skills`, `Projects`, `Journey`, `Contact`).
- `public/video/` — Background video for the scroll-scrubbed hero section.
